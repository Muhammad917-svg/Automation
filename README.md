## 💡 Customization

### Change Color Scheme
Edit the CSS variables in `styles/main.css`:

```css
:root {
    --primary-color: #ff6b9d;  /* Change to your color */
    --secondary-color: #c06c84;
    --accent-color: #6c5b7b;
    /* ... other variables */
}
```

### Modify Content
Edit the HTML in `index.html` to change:
- Titles and descriptions
- Feature items
- Gallery items
- Contact information

### Adjust Animations
Modify animation values in `styles/main.css`:
- Duration: `0.8s` → your duration
- Timing: `ease-out` → your timing function
- Transform effects: `translateY()`, `rotate()`, etc.
